# Infografía interactiva: sesgo algorítmico en la selección laboral

## Cómo abrir
1. Descarga y descomprime el proyecto.
2. Abre la carpeta `infografia-sesgo-algoritmico` en Visual Studio Code.
3. Abre `index.html` en tu navegador. Recomendado: extensión Live Server.
4. Para publicar, sube todos los archivos manteniendo la estructura de carpetas a un repositorio de GitHub y activa GitHub Pages desde Settings → Pages.

## Archivos
- `index.html`: contenido y estructura.
- `css/styles.css`: diseño responsive y animaciones.
- `js/script.js`: navegación, etapas interactivas, simulador y quiz.

## Personalización
- Cambia textos y secciones desde `index.html`.
- Ajusta colores en las variables `:root` de `css/styles.css`.
- Modifica interacciones y textos del simulador en `js/script.js`.

## Nota académica
El simulador contiene perfiles ficticios y no ejecuta un modelo de IA ni toma decisiones reales de contratación. Su objetivo es ilustrar por qué los criterios de evaluación deben ser pertinentes, transparentes y aplicados de forma consistente.
